# 2波源定在波干渉縞リアルタイム Canvas シミュレーター

2つの波源から放射する波の干渉縞（強め合い/弱め合い）をCanvas上でリアルタイムアニメーションするシミュレーター。各ピクセルで合成振幅 A·sin(k·r₁-ω·t) + A·sin(k·r₂-ω·t+Δφ) を計算し、正の振幅を青系、負の振幅を赤系で描画する。波長・振幅・角振動数・位相差をスライダーで調整でき、カラーモードも4種類から選べる。波源はキャンバス上をドラッグして自由に移動可能で、波源の距離や配置による干渉縞の変化を直感的に観察できる。

## 使い方

黄色（波源1）・水色（波源2）の点をドラッグして位置を変えると干渉縞がリアルタイムに更新される。スライダーで波の各パラメータを調整し、「停止」ボタンで時間発展を一時停止できる。
